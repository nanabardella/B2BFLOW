# 🚀 Desafio Técnico - b2bflow

## 🎯 Objetivo

Este projeto foi desenvolvido como parte do processo seletivo para Estágio em Desenvolvimento Python da b2bflow.

A aplicação realiza a leitura de contatos armazenados no Supabase e envia uma mensagem personalizada via WhatsApp utilizando a Z-API.

Mensagem enviada:

```text
Olá, <nome_contato> tudo bem com você?
```

---

## 🛠️ Tecnologias Utilizadas

* Python 3
* Supabase
* Z-API
* Requests
* Python Dotenv

---

## 🗄️ Estrutura da Tabela

Tabela utilizada no Supabase:

```sql
CREATE TABLE contatos (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome_contato TEXT NOT NULL,
    telefone TEXT NOT NULL
);
```

Exemplo de registros:

```sql
INSERT INTO contatos (nome_contato, telefone)
VALUES
('Giovanna', '5511999999999'),
('Maria', '5511988888888'),
('João', '5511977777777');
```

---

## 🔐 Variáveis de Ambiente

Criar um arquivo `.env` na raiz do projeto:

```env
SUPABASE_URL=sua_url_do_supabase
SUPABASE_KEY=sua_chave_do_supabase

ZAPI_INSTANCE_ID=seu_instance_id
ZAPI_TOKEN=seu_token
ZAPI_CLIENT_TOKEN=seu_client_token
```

## 📦 Instalação

## 📦 Instalação

Instale as dependências:

```bash
pip install -r requirements.txt
```

Ou individualmente:

```bash
pip install supabase python-dotenv requests
```

---

## ▶️ Execução

Execute o projeto com:

```bash
python main.py
```

---

## ⚙️ Funcionamento

1. Conecta ao Supabase.
2. Busca até 3 contatos cadastrados na tabela `contatos` utilizando o método `.limit(3)`.
3. Personaliza a mensagem utilizando o nome do contato.
4. Envia a mensagem via WhatsApp utilizando a Z-API.
5. Exibe logs de sucesso ou erro no terminal.
